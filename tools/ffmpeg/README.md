# Portable FFmpeg for HyperSpace

Place `ffmpeg.exe` (and optionally `ffprobe.exe`) in this folder so HyperSpace can
convert MP4/WebM/MOV to Theora `.ogv` for Godot's VideoStreamPlayer.

GIFs animate via the built-in GDScript decoder and do **not** require ffmpeg.

Download: https://www.gyan.dev/ffmpeg/builds/ (essentials build)
